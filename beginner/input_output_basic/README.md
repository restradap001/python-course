# Input/Output básico

## Descripción General
Aprende a interactuar con el usuario mediante la entrada y salida estándar en Python. Utiliza la función `input()` para recibir datos y `print()` para mostrar resultados.

## Características
- Leer datos del usuario con `input()`.
- Mostrar información en pantalla con `print()`.
- Convertir tipos de datos de entrada según sea necesario.

## Ejemplo
```python
nombre = input("¿Cómo te llamas? ")
print(f"Hola, {nombre}!")
```

## Buenas Prácticas
- Muestra mensajes claros al pedir datos.
- Convierte la entrada a los tipos necesarios (`int()`, `float()`, etc.).
- Usa f-strings para formatear la salida.
