# Operadores de comparación

## Descripción General
Los operadores de comparación permiten comparar valores y expresiones, devolviendo un resultado booleano (`True` o `False`). Son fundamentales para tomar decisiones en los programas.

## Operadores disponibles
- Igual a: `==`
- Distinto de: `!=`
- Mayor que: `>`
- Menor que: `<`
- Mayor o igual que: `>=`
- Menor o igual que: `<=`

## Ejemplo
```python
edad = 18
print(edad >= 18)  # True
print(edad != 21)  # True
```

## Buenas Prácticas
- Usa operadores de comparación en condiciones de estructuras `if`, `while`, etc.
- Recuerda que la comparación es sensible al tipo de dato.
