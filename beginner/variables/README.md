# Variables en Python

## Descripción General
Las variables son espacios en memoria donde se almacenan datos. En Python, se crean simplemente asignando un valor a un nombre.

## Reglas de Nombres
- Deben comenzar con una letra o guion bajo (_)
- No pueden contener espacios ni caracteres especiales
- Son sensibles a mayúsculas y minúsculas

## Ejemplo
```python
nombre = "Ana"
edad = 25
saldo = 100.50
```

## Buenas Prácticas
- Usar nombres descriptivos y en minúsculas.
- Inicializar variables antes de usarlas.
- Evitar el uso de variables globales innecesarias.
