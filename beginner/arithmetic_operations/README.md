# Operaciones Aritméticas en Python

## Descripción General
Las operaciones aritméticas son la base de cualquier lenguaje de programación. En Python, puedes realizar sumas, restas, multiplicaciones, divisiones, potencias, divisiones enteras y obtener el módulo (resto) de una división de manera sencilla y directa.

## Operadores Principales
- **Suma (`+`)**: Suma dos valores.
- **Resta (`-`)**: Resta el segundo valor al primero.
- **Multiplicación (`*`)**: Multiplica dos valores.
- **División (`/`)**: Divide el primer valor entre el segundo (resultado flotante).
- **División entera (`//`)**: Divide y devuelve solo la parte entera del resultado.
- **Módulo (`%`)**: Devuelve el resto de la división.
- **Potenciación (`**`)**: Eleva un número a la potencia de otro.

## Ejemplo Básico
```python
x = 10
y = 3
print(x + y)  # Suma
print(x - y)  # Resta
print(x * y)  # Multiplicación
print(x / y)  # División
print(x // y) # División entera
print(x % y)  # Módulo
print(x ** y) # Potencia
```

## Aplicaciones Comunes
- Cálculo de totales y promedios
- Conversión de unidades
- Operaciones financieras y científicas

## Buenas Prácticas
- Usar paréntesis para agrupar operaciones y evitar ambigüedades.
- Recordar la precedencia de operadores: potencias > multiplicación/división > suma/resta.
- Convertir tipos de datos cuando sea necesario (por ejemplo, de string a int o float).
