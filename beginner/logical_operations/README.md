# Operaciones Lógicas en Python

## Descripción General
Las operaciones lógicas permiten combinar y evaluar condiciones booleanas. Son fundamentales para la toma de decisiones en los programas.

## Operadores Lógicos
- **and**: Verdadero si ambas condiciones son verdaderas.
- **or**: Verdadero si al menos una condición es verdadera.
- **not**: Invierte el valor lógico (True a False y viceversa).

## Ejemplo
```python
edad = 20
es_estudiante = True
if edad >= 18 and es_estudiante:
    print("Descuento aplicado")
```

## Aplicaciones Comunes
- Validación de acceso
- Filtros y búsquedas
- Control de flujo en programas

## Buenas Prácticas
- Agrupar condiciones complejas con paréntesis.
- Usar nombres de variables descriptivos para condiciones.
